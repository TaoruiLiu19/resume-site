跨域推荐系统 · 知识图谱 + 强化学习

GitHub

本科毕业论文工作。完整复现并改进 KR-CDR 模型（IEEE TNNLS 2025），利用强化学习自动推理跨域元路径，缓解重叠用户稀疏导致的推荐性能下降问题。

  • 实现跨域知识图谱构建、TransE 嵌入预训练、Actor-Critic + Meta-Net 联合训练、束搜索路径推理与双层注意力聚合
  • 在 Amazon Reviews 2018 三个领域对上进行实验，Ap-By 上 NDCG@10 与论文差距 ≤5.1%
  • 提出残差连接与 Dropout 正则化改进，Lb-By 上 NDCG@10 从 0.3218 提升至 0.4438（+37.8%），与论文值差距缩小至 1.1%
PyTorch DGL-KE 强化学习 TransE Actor-Critic

NovelCraft · AI 小说创作辅助工具

GitHub

基于 DeepSeek V4-Flash 百万 token 上下文窗口的长篇小说创作辅助工具，解决 AI 续写时遗忘前文的工程问题。

  • 按创作流程拆分为独立模块：大纲生成、人物小传与关系图、润色扩写、角色对白、全书记忆引擎
  • 利用 100 万 token 上下文一次性加载约 90 万字全文，保证人物一致性与伏笔连贯
  • 基于 Streamlit 构建交互界面，依赖极简，pip 安装即可运行
